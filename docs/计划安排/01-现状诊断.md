## 一、当前已实现模块

### 1.1 练习模块（nvcpractice）— 核心模块

**已实现：**
- 3 种练习模式：SCENARIO（场景驱动）、FREE_DIALOG（自由对话）、STRUCTURED_FOUR_STEP（结构化四步）
- Agent 调度：NvcAgentOrchestrator + ModeRouter 策略模式
- 10 种 Agent 场景（NvcAgentScene 枚举）
- 对话服务：NvcAgentChatService（支持工具调用）
- 评估服务：NvcEvaluationService（5 维度：观察/感受/需求/请求/共情）
- 摘要服务：NvcSummaryService（四要素提取，异步）
- 结构化练习：NvcStructuredPracticeService（四步推进）
- Agent 配置热更新（DB + Redis 缓存，5 分钟 TTL）
- 流式 SSE 对话 + 非流式对话
- Agent 配置管理页面（前端）
- **Agent 工具调用框架**：NvcTool 接口 + NvcToolRegistry + 15 个工具类
- **场景推荐服务**：NvcScenarioRecommendService（4 维度加权排序）
- **IntentRouter 集成**：意图识别 + 工具路由

### 1.2 主 Agent 模块（nvcassistant）— Phase 2 新增

**已实现：**
- **AgentLoop**：自建 Agent 主循环，internalToolExecutionEnabled=false
- **7 层 Hook 链**：RateLimit → Permission → Cache → ErrorEnhance → EvaluationTrigger → Persist → Logging
- **ContextManager**：LLM 摘要压缩（>20 条消息 → 保留 10 条 + 摘要）
- **PromptBuilder**：动态系统提示词 + CoT 引导
- **NvcAssistantController**：6 个 API（chat/stream/conversations/messages/delete/regenerate）
- **NvcAssistantMessageService**：对话 + 消息管理，20 轮滑窗
- **IntentRouter**：意图识别路由
- 前端页面：NvcAssistantPage + NvcAssistantChat + NvcToolCallCard

### 1.3 场景库模块（nvcscenario）

**已实现：**
- 场景 CRUD（标题/描述/类型/难度/标签）
- AI 生成场景（结构化 JSON 输出）
- 5 种场景类型：WORKPLACE/FAMILY/INTIMATE/SOCIAL/SELF
- 13 个种子场景
- 使用次数统计

### 1.4 用户档案模块（nvcprofile）

**已实现：**
- 档案 CRUD（沟通背景/性格特征/沟通风格/情绪触发器）
- 能力分数管理（观察/感受/需求/请求/共情，5 维度）
- 能力雷达图（最近 10 次平均）
- 能力趋势图（最近 30 次）
- 沟通记录分析（AI 分析真实沟通场景）
- NVC 等级自动计算（BEGINNER/INTERMEDIATE/ADVANCED）
- 仪表盘统计

### 1.5 知识库模块（knowledgebase）

**已实现：**
- 文档上传（PDF/DOCX/TXT/MD，Apache Tika 解析）
- 文档分块（TokenTextSplitter，800 tokens/chunk）
- 向量化（DashScope text-embedding-v3，1024 维）
- RAG 查询（向量检索 + 查询重写 + 动态参数）
- 异步向量化管线（Redis Stream）
- 知识库 CRUD + 统计
- **KnowledgeBaseType 枚举**（NVC_THEORY / SPEECH_TEMPLATE / EMOTION_VOCAB / USER_CASE / PERSONAL_WIKI）
- **15 份 NVC 知识文档**（theory/vocabulary/templates/cases）
- **SeedKnowledgeBaseService**：自动种子数据服务
- **NvcRagService**：NVC 专用 RAG 检索 + 个性化检索

### 1.6 Wiki 模块（nvcwiki）— Phase 2 新增

**已实现：**
- 复用 knowledge_base 表（type=PERSONAL_WIKI，userId 隔离）
- Wiki CRUD + 语义搜索
- 自动沉淀（练习结束后 AI 生成学习笔记）
- 手动记录 + AI 辅助生成
- WikiWriteTool / WikiSearchTool 工具实现
- 前端页面：NvcWikiPage + NvcWikiEditor + NvcWikiCard + NvcWikiSearch

### 1.7 语音模块（nvcvoice）

**已实现：**
- WebSocket 语音练习
- ASR（Qwen 语音识别）
- TTS（Qwen 语音合成）
- 语音会话管理
- 语音评估
- 模块化管线架构（OrderedTtsChunkEmitter、UtteranceMergeBuffer、VoicePipelineCoordinator）
- Provider 接口化（AsrProvider / TtsProvider）

### 1.8 LLM Provider 模块（llmprovider）

**已实现：**
- 多 Provider 管理（DashScope/LmStudio/Kimi/DeepSeek/GLM/MiMo）
- API Key 加密存储
- ChatClient 缓存（ConcurrentHashMap）
- EmbeddingModel 管理
- 结构化输出（BeanOutputConverter + 重试 + 修复）

### 1.9 LLMOps 层 — Phase 2 面试亮点新增

**P0-1 量化指标采集：**
- MetricsCollector + AgentMetricsEntity + Redis Stream 异步落库
- MetricsStatsService + MetricsController（5 个 API）
- Golden Dataset 30 条 + EvaluationConsistencyVerifier
- NvcAgentOrchestrator 集成推荐服务 + /recommendations API

**P0-2 Trace 可观测体系：**
- AgentTraceEntity/SpanEntity + TraceManager（ThreadLocal）
- TraceStreamProducer/Consumer + TraceController（4 个 API + 离线评估 API）
- OfflineEvaluationService（4 维度评估）
- 4 个组件 Trace 埋点（AgentLoop/ToolExecutor/ContextManager/IntentRouter）
- 前端 8 个文件（TraceListPage/TraceDetailPage/TraceTimeline 等）

**P0-3 LLM Fallback 降级：**
- LlmFallbackHandler（3 次重试 + 分类降级）
- DialogFallbackTemplates（27 条 NVC 引导话术）
- KeywordScorer（四维度关键词评分）
- EvaluationFallbackService（降级评估 + degraded 标记）
