## Executive Summary

NVC Guide 采用模块化单体架构（Spring Boot 4.0 + React 18），整体结构清晰但存在多个严重的代码坏味道。最突出的问题是 **God Object**（2 个超大类）、**Long Method**（多个方法超过 100 行）、和 **Magic Numbers**（硬编码数字散落各处）。跨模块耦合违反了分层原则，common 层反向依赖 modules 层。测试覆盖率极低（后端 16%、前端 7%），且存在 7 个确认的死代码组件。代码风格方面，命名规范总体一致，但存在数据类（Anemic Domain Model）和重复代码。

**整体健康度：🟡 Fair** — 功能完成度高，但技术债正在积累。

## Detailed Findings

### Finding #1: God Object — LlmProviderConfigService

- **Category:** Cohesion
- **Severity:** 🔴 Critical
- **Anti-Pattern:** God Object / SRP Violation
- **Location:** `app/.../llmprovider/service/LlmProviderConfigService.java` (1217 行)
- **Principle Violated:** Single Responsibility Principle
- **Description:** 单个类承担 7+ 职责：Provider CRUD、YAML 文件编辑（含内部类 YamlTextEditor）、.env 文件管理、REST 连通性测试、ASR/TTS 配置、API Key 加密、Provider 运行时配置。包含 20+ 公共方法。
- **Evidence:** 内部类 `YamlTextEditor` 在 line 1058；`doTestProvider()` 和 `testAsrConfig()` 包含 HTTP 连通性测试逻辑；`updateEnvFile()` 直接操作 .env 文件
- **Recommendation:** 拆分为：1) LlmProviderCrudService（CRUD）2) ConfigFilePersistenceService（YAML/.env 操作）3) ProviderConnectivityService（连通性测试）4) AsrTtsConfigService（ASR/TTS 配置）

### Finding #2: God Object — SettingsPage.tsx

- **Category:** Cohesion
- **Severity:** 🔴 Critical
- **Anti-Pattern:** God Object / SRP Violation
- **Location:** `frontend/src/pages/SettingsPage.tsx` (1500 行)
- **Principle Violated:** Single Responsibility Principle
- **Description:** 单个 React 组件处理 LLM Provider CRUD、Provider 预设、ASR/TTS 配置、Embedding 配置、表单状态管理、模态框控制、Toast 通知。所有状态和逻辑集中在一个组件中。

### Finding #5: Violated Layer Boundaries — Common → Modules

- **Category:** Architecture
- **Severity:** 🔴 Critical
- **Anti-Pattern:** Violated Layer Boundaries
- **Location:** `common/ai/LlmProviderRegistry.java` imports `modules/llmprovider/*`; `common/trace/HttpTraceInterceptor.java` imports `modules/nvcassistant/*`
- **Principle Violated:** Dependency Inversion Principle
- **Description:** Common 层（应该是最底层）反向依赖 modules 层（应该是上层）。这使得 common 层无法独立复用，模块变更可能影响基础设施。
- **Recommendation:** 在 common 层定义接口（如 LlmProviderResolver），modules 层实现。使用 Spring @Qualifier 注入。

### Finding #6: Circular Dependencies — nvcassistant ↔ nvcpractice

- **Category:** Coupling
- **Severity:** 🔴 Critical
- **Anti-Pattern:** Circular Dependencies
- **Location:** `nvcassistant/service/agent/AgentLoop.java` imports nvcpractice 工具类；`nvcpractice/service/NvcAgentOrchestrator.java` imports nvcprofile 和 nvcscenario
